# The Vedas: image credits

All three images are public-domain Open Access photographs from The Metropolitan Museum of Art. The official Collection API returned `isPublicDomain: true` for each object on 2026-10-13. Local WebP copies are resized so the longest side is at most 1400px, without cropping or retouching. Astro generates responsive sizes. No reconstructed or generated imagery is presented as an ancient object.

None of these objects is Vedic. The hymns of the Rigveda describe no images, and each plate was made between about 1,200 and 2,000 years after them; the chapter's captions say so. The bronze's identity is uncertain in the museum's own title. The Indra photograph shows only the head of a figure that survives in two pieces, and the inscription naming him is on the pedestal, which is not shown. The Varuna photograph is the museum's only image, an old black-and-white one 797px wide, used at its original size; its record has no description or findspot. There is deliberately no plate for Soma.
