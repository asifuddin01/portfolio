# Before the world: image credits

The three images are public-domain Open Access photographs from The Metropolitan Museum of Art. The Collection API reported `isPublicDomain: true` for each object on 2026-10-03. Local WebP copies are resized to a maximum width of 1280 px without cropping or retouching. The chapter uses Astro's responsive Image component.
