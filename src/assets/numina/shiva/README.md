# Shiva: image credits

All images are public-domain Open Access photographs from The Metropolitan Museum of Art. The official Collection API returned `isPublicDomain: true` for each object on 2026-10-13. Local WebP copies are resized so the longest side is at most 1400px, without cropping or retouching; where the museum's only photograph is smaller than that, it is used at its original size. Astro generates responsive sizes. No reconstructed or generated imagery is presented as an ancient object. The diagrams on these pages are inline SVG drawn for this book and are labelled as diagrams, not plates.
