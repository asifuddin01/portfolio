<Statement>
Compute every output of a small valid cross-correlation.
</Statement>
<Given>
One input channel and one output channel, stride one, no padding,
dilation one and zero bias:

$$
\begin{aligned}
X&=\begin{bmatrix}1&2&0\\0&1&3\\2&1&0\end{bmatrix},\\[6pt]
K&=\begin{bmatrix}1&0\\-1&2\end{bmatrix}.
\end{aligned}
$$
</Given>
<Find>
The output shape, four output values, parameter count with a trainable bias,
and main-product multiply-accumulates.
</Find>
<Strategy>
Place the stored kernel on each complete window. Do not flip it.
Use (I.11.4) for shape and (I.11.2) for the count.
</Strategy>
<Solution>

Each axis has $3-2+1=2$ outputs. The four sums are

$$
\begin{aligned}
Y_{0,0}&=1(1)+2(0)\\
 &\quad+0(-1)+1(2)=3,\\
Y_{0,1}&=2(1)+0(0)\\
 &\quad+1(-1)+3(2)=7,\\
Y_{1,0}&=0(1)+1(0)\\
 &\quad+2(-1)+1(2)=0,\\
Y_{1,1}&=1(1)+3(0)\\
 &\quad+1(-1)+0(2)=0.
\end{aligned}
$$

Thus $Y=\begin{bmatrix}3&7\\0&0\end{bmatrix}$.
There are four kernel weights and one bias, or five parameters.
Four output windows use four weights each, giving 16 multiply-accumulates.
A zero current bias is still a parameter if it is trainable.

</Solution>
<Answer>
Output shape $(1,2,2)$, values $[[3,7],[0,0]]$, five parameters and 16
main-product multiply-accumulates.
</Answer>
<CheckSanity>
The lower windows contain nonzero inputs but have zero output because positive
and negative contributions cancel. A zero response need not mean an empty patch.
</CheckSanity>

<Breaks>
Flipping the kernel changes the operation. Adding channels requires summing
their responses before adding the output channel's bias once.
</Breaks>
<Variation>
Set the bias to one. Every output increases by one, producing
$[[4,8],[1,1]]$, while the parameter count remains five.
</Variation>
