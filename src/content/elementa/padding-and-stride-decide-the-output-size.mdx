## Count the last window that fits

Work along one axis. The unpadded input has length $n$, the left and right
padding widths are $p_L,p_R$, kernel width is $k$, dilation is $d$,
and stride is $s$. The effective kernel span is $e=d(k-1)+1$.

A window with origin $qs$ in padded coordinates occupies positions
$qs$ through $qs+e-1$. It fits exactly when
$qs+e-1\leq n+p_L+p_R-1$. Therefore
$q\leq(n+p_L+p_R-e)/s$. Counting integer origins starting at zero yields

<Eq id="I.11.4" gloss="The floor comes from counting complete windows, not from a rounding preference.">

$$
\begin{aligned}
e&=d(k-1)+1,\\
n_{\mathrm{out}}
 &=\left\lfloor\frac{n+p_L+p_R-e}{s}\right\rfloor+1.
\end{aligned}
$$

</Eq>

Equation (I.11.4) assumes positive integer kernel, stride and dilation,
non-negative padding, and at least one fitting window.
A padded input smaller than the effective kernel is not a valid positive-sized
output for this convention. Apply the same derivation independently to height
and width.

For $n=7$, $k=3$, $d=1$, $p_L=p_R=1$ and $s=2$,
the result is $\lfloor(7+2-3)/2\rfloor+1=4$.
The padded origins are $0,2,4,6$.
Origin eight would overrun the padded length nine and is not evaluated.

The diagram compares this with the stride-one outputs of widths five and
seven. [I.11.B03](/elementa/neural-networks/convolution/problems/b03) adds
channels, batches and dilation.

## “Same” must name an alignment convention

At stride one, keeping the input size requires total padding $e-1$.
If $e$ is odd this can be split equally. If $e$ is even, equal integer
padding cannot give exactly that total.

A common stride-$s$ convention chooses output length $\lceil n/s\rceil$
and total padding

$$
P=\max\left(0,(\lceil n/s\rceil-1)s+e-n\right).
$$

When $P$ is odd, assigning the extra element to the left rather than the
right changes alignment even though the shape is identical.
Frameworks do not all support the same named modes for every stride;
the documented PyTorch Conv2d string mode 'same', for example, requires
stride one. Record actual padding widths when reproducing a model.

Two arrays can have equal shapes and refer to different input centres.
For a feature whose preceding input-centre jump is $J$, a layer shifts the
first centre by $((e-1)/2-p_L)J$. With even kernels this may be a half-grid
offset. Shape equality alone is not sufficient evidence that decoder and
skip-connection features align spatially.

## A transposed convolution follows the backward connectivity

Flatten a bias-free convolution into a matrix $A$ so that $y=Ax$.
Then a linear objective with upstream vector $g$ has input gradient
$A^{\mathsf T}g$. A transposed convolution computes this adjoint connectivity,
summing contributions wherever output windows overlap.

For symmetric padding, its common one-axis shape formula is

<Eq id="I.11.5" gloss="A shape choice resolves stride ambiguity; it cannot reverse information loss.">

$$
\begin{aligned}
n_{\mathrm{transposed}}
 ={}&(n_{\mathrm{in}}-1)s-2p\\
 &+d(k-1)+o+1.
\end{aligned}
$$

</Eq>

Here $o$ is the output-padding shape parameter. In the usual stride-ambiguity
case choose $0\leq o<s$; consult the operator's documented constraints for
other dilation combinations.
Different input sizes can have the same forward output size because of the
floor in (I.11.4). The parameter $o$ selects a compatible output shape.

It does not mean that the operator pads missing observations back into
existence. A map from four coordinates to two cannot have a two-sided inverse.
[I.11.X07](/elementa/neural-networks/convolution/problems/x07) writes its
matrix, verifies the adjoint identity and chooses the output shape explicitly.

For segmentation, upsampling restores the size of a prediction grid.
Whether it restores useful detail depends on the representations available
to the decoder. Equal image dimensions do not prove reconstruction.
