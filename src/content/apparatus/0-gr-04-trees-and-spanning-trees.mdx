title: "Trees and spanning trees"
statement: "A tree is a connected acyclic graph; on n vertices it has exactly n−1 edges, and between any two vertices there is exactly one path. A spanning tree of G is a tree using all of G's vertices; a minimum spanning tree minimises total edge weight."
shapeCheck: "n vertices, n−1 edges, one unique path per pair. Adding any edge to a tree creates exactly one cycle."
workedLine: "Four vertices in a square with unit weights: any three of the four edges form a spanning tree of weight 3."
status: review

A phylogeny is a tree, and the uniqueness of the path between two leaves is what makes an evolutionary distance well defined. Where that uniqueness fails, the object is a network — which is the subject of VII.8.
