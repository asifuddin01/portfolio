title: "MONAI — the metric that hid the failures"
summary: "An upstream contribution to MONAI, the medical imaging library that most segmentation work in this field is built on. Found by running its segmentation metrics against the degenerate cases retinal lesion work produces — empty masks, single-pixel structures, predictions that miss entirely — because that is where a widely used library is least tested and where my own data lives. HausdorffDistanceMetric answers the same input two different ways: the maximum returns inf for a prediction that found nothing, which is honest, and every percentile returns nan. HD95 is the headline metric in medical segmentation and nan is that metric's not-applicable sentinel, so do_metric_reduction drops it before averaging. The failures leave the score. Over a hundred images where the only variable is how many the model misses, the reported HD95 does not move: a model that finds nothing in ninety-nine of them scores the same as one that finds the lesion every time, because the average was taken over the one case that worked. The cause is torch.quantile interpolating between two infinities, inf + (inf - inf) * frac, which the max and min paths escape because they do not interpolate. Reproduced on released 1.6.0 as well as on dev, so it affects installs in use rather than only unreleased code. Fixed by returning the infinity directly, with twelve regression tests over both entry points at every percentile — without the source change eight fail and four pass, and the four are exactly the non-interpolating paths, which is the fix checking its own diagnosis."
cvSummary: "Open-source contribution to MONAI (Project-MONAI/MONAI, 8.7k stars), the standard medical imaging framework. Found and fixed a silent correctness bug in HausdorffDistanceMetric: a prediction that misses the structure entirely returns nan at every percentile where the maximum returns inf, and nan is excluded from the reduction, so failed cases are dropped from a dataset HD95 rather than scored. Demonstrated that the reported metric does not move as a model degrades from 0 to 99 misses in 100 images. Traced to torch.quantile interpolating between two infinities; fixed with a guard and twelve regression tests, verified failing before and passing after. Reported as issue #9095, fixed in PR #9096."
