## What it does

A scoped symbol table for a compiler front end, written with lex and yacc/bison.

## How it works

- **Lookup.** A hash table that hashes the sum of a name's characters modulo the bucket count.
- **Scopes.** A scope stack, kept through parent pointers.
- **Where names land.** A `scope_started` flag with mid-rule actions, so function parameters land inside the function's scope, while `if` and `for` blocks get scopes of their own.

## Portable

It builds and runs on both macOS and Linux.
