definitions:
  - n: 1
    term: "Kernel"
    statement: "A small array of shared weights. In an ordinary two-dimensional layer, each output channel has one spatial kernel for each input channel; their responses are added."
    introduces: []
  - n: 2
    term: "Cross-correlation"
    statement: "Multiplying a window by the kernel in its stored orientation and summing. Common CNN layers call this convolution. Mathematical convolution reverses the kernel along each spatial axis."
    introduces: []
  - n: 3
    term: "Feature map"
    statement: "The spatial array of activations in one channel. A convolutional layer normally returns several feature maps; an activation function is a separate operation."
    introduces: []
  - n: 4
    term: "Stride"
    statement: "The spacing between successive kernel origins in the input grid. A stride above one samples fewer output locations and changes which translations preserve the output sampling grid."
    introduces: []
  - n: 5
    term: "Padding"
    statement: "The boundary extension applied before evaluating windows. Zero, reflection and circular padding are different functions. The number of added positions can differ on the two sides."
    introduces: []
  - n: 6
    term: "Dilation"
    statement: "The spacing between adjacent kernel taps. A kernel of width k and dilation d spans d(k - 1) + 1 input positions while retaining k weights along that axis."
    introduces: []
  - n: 7
    term: "Receptive field"
    statement: "The input positions that can influence a chosen output through the computation graph. Its bounding span may contain holes, and possible influence need not mean a large learned derivative."
    introduces: []
  - n: 8
    term: "Translation equivariance"
    statement: "Shifting an input shifts its output by the corresponding amount. This differs from invariance, where the output stays unchanged. Boundaries and subsampling restrict an equivariance claim."
    introduces: []
  - n: 9
    term: "Pooling"
    statement: "A fixed reduction over a spatial window, often its maximum or mean. Pooling usually operates independently per channel. Window size, stride and padding remain part of its definition."
    introduces: []
  - n: 10
    term: "Grouped and depthwise convolution"
    statement: "A grouped layer splits input and output channels into disjoint groups. Depthwise convolution uses one group per input channel, optionally with several output filters per channel. A following pointwise layer can mix channels."
    introduces: []
  - n: 11
    term: "Transposed convolution"
    statement: "The linear adjoint of a chosen convolutional map, implemented with its transposed connectivity. It distributes input values into overlapping output windows. It does not generally reconstruct the input of the original map."
    introduces: []

formalResults:
  - id: "I.11.T1"
    name: "Stride-one convolution commutes with translation on an unrestricted grid"
    statement: "For F_K(X)[i,j] = sum_(c,u,v) K[c,u,v] X[c,i+u,j+v] and translation T_a X[i,j] = X[i-a_1,j-a_2], substitution gives F_K(T_a X) = T_a F_K(X). A spatially constant bias and pointwise activation preserve this property."
    doesNotPromise: "A finite crop with boundary padding may break the identity near its edges. Stride s preserves the correspondence only for translations aligned with that sampling lattice. Equivariance does not imply an unchanged classification output."
  - id: "I.11.T2"
    name: "Shared-kernel gradients sum over every window"
    statement: "For one stride-one valid channel, Y[i,j] = sum_(u,v) K[u,v] X[i+u,j+v] + b and upstream G, dL/dK[u,v] = sum_(i,j) G[i,j] X[i+u,j+v]. The input derivative accumulates G[i,j] K[u,v] at each participating input entry. I.11.B02 derives both and checks them by finite differences."
    doesNotPromise: "No additional kernel flip belongs in this scatter-add rule. A different convolution convention, stride, dilation or padding changes the index map. Padding constants are not trainable input values."
  - id: "I.11.T3"
    name: "Receptive-field span follows the preceding sampling jump"
    statement: "For a sequential stack, start with R_0 = J_0 = 1. At layer l, effective kernel width is e_l = d_l(k_l - 1) + 1; then R_l = R_(l-1) + (e_l - 1)J_(l-1) and J_l = s_l J_(l-1). Apply separately to height and width."
    doesNotPromise: "This gives a bounding span and sampling jump for local layers, not the learned strength of influence. Dilation may leave holes. Global operations, branching and boundary alignment need their own dependency accounting."

failureModes:

  - "A zero-filled boundary can break translation equivariance. I.11.X03 shifts a finite three-value input and gets a different edge response from shifting the original output."
