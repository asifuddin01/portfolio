definitions:
  - n: 1
    term: "Loss function"
    statement: "A loss ℓ : 𝒴 × 𝒴 → ℝ₊ assigns one non-negative number to a single prediction–target pair, smaller meaning better. It must be differentiable in its first argument almost everywhere, because that argument is what the optimiser moves. Nothing in the data selects it."
    introduces:
      - "L_loss"
  - n: 2
    term: "Reduction"
    statement: "The reduction is the function turning per-example losses into the one scalar that is differentiated — almost always the arithmetic mean. The choice is invisible in the formula and decides how much each example contributes to the gradient."
    introduces: []
  - n: 3
    term: "Mean squared error"
    statement: "MSE = (1/n) Σ (ŷᵢ − yᵢ)². Its derivative with respect to a residual is proportional to that residual, so a residual twice as large pulls twice as hard and one ten times as large pulls ten times as hard."
    introduces: []
  - n: 4
    term: "Mean absolute error"
    statement: "MAE = (1/n) Σ |ŷᵢ − yᵢ|. Its derivative with respect to a residual is ±1 regardless of magnitude, so every example pulls equally hard whatever its error. It is not differentiable at zero."
    introduces: []
  - n: 5
    term: "Huber loss"
    statement: "Huber_δ(r) = ½r² for |r| ≤ δ and δ(|r| − ½δ) otherwise. It is quadratic near zero and linear beyond δ, so it is differentiable everywhere and its derivative is bounded by δ."
    introduces: []
  - n: 6
    term: "Logit"
    statement: "A logit is an unnormalised real-valued score, before any function maps it to a probability. Logits live on all of ℝ; probabilities live in (0,1). Every numerically sound loss in this chapter is computed from logits, never from probabilities."
    introduces: []
  - n: 7
    term: "Softmax"
    statement: "softmax(z)ᵢ = e^{zᵢ} / Σⱼ e^{zⱼ}, mapping a logit vector to the probability simplex. It is invariant to adding a constant to every logit, which is why it can be computed after subtracting the maximum without changing the answer."
    introduces:
      - "softmax"
  - n: 8
    term: "Cross-entropy"
    statement: "For a target distribution p and a predicted q, H(p, q) = −Σ p(x) log q(x). With p one-hot it collapses to −log q(c) for the true class c, so all but one term of the sum vanish."
    introduces:
      - "Hent"
  - n: 9
    term: "Label smoothing"
    statement: "Label smoothing replaces the one-hot target by (1 − ε)·onehot + ε/K applied uniformly. It caps the reward for confidence: the loss is then minimised at a finite logit gap rather than at an infinite one."
    introduces: []

formalResults:
  - id: "I.4.T1"
    name: "Losses as negative log-likelihoods"
    statement: "Minimising MSE is exactly maximising the likelihood of a Gaussian observation model with fixed variance; minimising cross-entropy is exactly maximising the likelihood of a categorical model. In both cases the loss is −log p(y | x, θ) up to an additive constant and a positive scale, neither of which changes the minimiser."
    doesNotPromise: "It does not promise the implied noise model is true of your data. Choosing MSE asserts symmetric, constant-variance, unbounded Gaussian errors — an assertion that is false for counts, for bounded quantities, and for anything heavy-tailed. The correspondence is a fact about the algebra, not evidence about the world, and it is most dangerous when nobody realises an assertion was made."
  - id: "I.4.T2"
    name: "Bayes-optimal predictors"
    statement: "Under squared loss the risk-minimising prediction at x is the conditional mean 𝔼[Y | X = x]; under absolute loss it is a conditional median; under cross-entropy it is the true conditional distribution p(· | x). Each is derived by differentiating the expected loss and setting it to zero."
    doesNotPromise: "These describe the minimiser over all measurable functions, not over the hypothesis class the model actually searches. A network trained on squared loss approaches the conditional mean only insofar as the mean lies in its class and the optimiser finds it — two conditions I.1.T1 and I.3.T2 already warned are separate. They also assume the training distribution equals the deployment one."

failureModes:
  - "Squared loss through a sigmoid stops sending gradient exactly where the model is most wrong. At logit z = −10 with target 1, MSE's gradient is 4.54e-5 while cross-entropy's is 0.99996 — a ratio of 22,029. At z = −20 the ratio is 4.85e+8. The model is as wrong as it can be and MSE reports almost nothing."
  - "Naive binary cross-entropy raises an exception on ordinary logits. Computing p = sigmoid(z) then log(p) at z = −800 overflows exp(800) to infinity, giving p = 0 and log(0); at z = +800 with target 0, sigmoid rounds to exactly 1.0 and log(1 − 1) fails. The stable identity returns 800.000000 in both cases."
